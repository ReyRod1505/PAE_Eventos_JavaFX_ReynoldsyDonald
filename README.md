# PAE - Sistema de Eventos JavaFX

Proyecto académico desarrollado con **JavaFX 21** y **Maven**, modularizada para la gestión de eventos e inventarios divididos en tres retos.

---

## Tecnologías Utilizadas

* **Lenguaje:** Java 21
* **Framework GUI:** JavaFX 21 (Controls, FXML, Graphics)
* **Gestor de Dependencias:** Maven
* **Control de Versiones:** Git & GitHub

---

##  Estructura del Proyecto

El sistema está empaquetado por funcionalidades dentro de `ni.edu.uam.pae_eventos_javafx_reynoldsydonald`:

* **Menú Principal (`HelloApplication` / `HelloController`):** Punto de entrada que permite navegar dinámicamente hacia cualquiera de los tres retos.
* **Reto 1 - Inventario de Pulpería:** Captura y control de eventos del teclado (`KeyEvent`) y botones (`ActionEvent`).
* **Reto 2 - Recepción de Café:** Manejo de tablas interactivas (`TableView`), registro dinámico, detalles con eventos de ratón (`MouseEvent`), y menú contextual (`ContextMenu`).
* **Reto 3 - Tienda de Artesanías:** Interfaz avanzada estructurada con barras de menú (`MenuBar`) y barras de herramientas (`ToolBar`).
